# Register a catalog in the Portolan registry

Read the current [registry README](https://github.com/portolan-sdi/portolan-registry/blob/main/README.md) and find the submission instructions.
Follow them for the user's catalog, including linked validation guidance and contribution requirements.
Use the user's preferred submission method.

Ask for required information the user has not supplied.
Never guess the submitter email address or read it from git config.

Complete the submission and return its URL.
If blocked, report what the user needs to provide or fix.
